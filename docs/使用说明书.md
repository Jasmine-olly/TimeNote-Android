## 一、产品简介

### 1.1 它是做什么的

TimeNote 帮你：

- **看见时间**：标记出手机里的「娱乐应用」（小红书、淘宝、抖音…），它们一被使用就浮出计时胶囊，让你对「时间花在哪」有实感——不封锁、不强拆，只温柔地提醒。
- **定时自省**：自定义「时间 → 问题」，到点弹窗问你（如「此刻你的专注度如何？」），把当下的感受碎片采集下来；错过还能补答。
- **沉淀日记**：每天自动把「娱乐统计 + 提问回答」汇编成一篇 Markdown 日记，可手动编辑、可设封面、像翻实体日记本一样左右翻阅。

### 1.2 核心理念

| 理念 | 含义 |
|---|---|
| 温柔 | 只提醒、不强制；「再玩5分钟」「关闭提醒」都是把选择权还给你 |
| 私密 | **零联网、零上传**，所有数据只存在本机 |
| 完整 | 每天的数据 + 感受自动沉淀成日记，可导出拿走 |

### 1.3 功能一览

| 功能 | 一句话 |
|---|---|
| 娱乐监督（F1） | 勾选娱乐 App → 悬浮计时 → 阈值提醒 → 退出引导 |
| 定时提问（F2） | 时间+问题配对 → 到点弹窗 → 待回答补答 |
| 日记（F3） | 自动汇编 + 手动编辑 + 封面 + 左右翻页 + 自动同步回答 |
| 统计 | 周报/月报可视化（娱乐趋势、应用排行、回答率） |
| 导出 | 日记 Markdown / 全部数据 JSON，本地保存 |

## 二、界面总览

底部有 **5 个入口**：

```
⏱ 监督    ❓ 提问    📓 日记    📊 统计    📤 导出
```

| Tab | 作用 |
|---|---|
| **监督** | 开启/关闭监督、管理娱乐清单、设置提醒阈值、查看权限状态 |
| **提问** | 待回答列表、问题计划（增删改/暂停） |
| **日记** | 日历/封面切换、看日记、编辑、翻页 |
| **统计** | 周报/月报数据图表 |
| **导出** | 把数据导出成文件 |

## 三、安装与权限

### 3.1 安装

- 本项目是 debug 包（`app/build/outputs/apk/debug/app-debug.apk`），用 `adb install -r` 覆盖安装。
- 升级会保留数据（Room 自动迁移）。

### 3.2 需要开启的权限（在「监督」页会提示）

| 权限 | 用途 | 不开启的后果 |
|---|---|---|
| **悬浮窗**（显示在其他应用上层） | 悬浮计时胶囊、阈值弹窗 | 计时器不显示、弹窗不能后台弹出 |
| **使用情况访问** | 检测前台应用、统计娱乐时长 | 计时/统计无数据 |
| **无障碍服务**（可选） | 实时（秒级）前台检测 | 检测退化为每 5 秒的 UsageStats，稍有延迟 |
| **通知**（Android 13+） | 前台服务常驻通知、到点提问兜底通知 | 收不到提问通知兜底 |
| **精确闹钟**（Android 12+） | 定时提问准时触发 | 提问到点延迟（走降级窗口闹钟） |

> **精确检测**：监督页的「精确检测」开关决定是否使用无障碍做实时检测——开 = 实时（需无障碍）；关 = 纯系统 5 秒延时（无需无障碍）。无障碍引导已合并进该卡片，权限状态页不再单列。
>
> vivo（OriginOS）提示：以上多为「特殊访问权限」，需到系统设置里逐项手动开启；应用内的权限卡片会引导你跳转。部分权限可能被 ROM 的「耗电管理/自启动」限制，建议把 TimeNote 加入自启动白名单，否则开机后需打开一次 App 重新登记闹钟。

## 四、功能详解：娱乐监督（F1）

### 4.1 娱乐清单

- 「监督」页 →「娱乐应用清单」，点击「＋」扫描手机里所有可启动的应用，**按名称排序**（中文按拼音）。
- 勾选 = 视为娱乐应用，长时生效；取消勾选即移除。
- 新装的应用下次打开本页会出现；卸载的应用消失。

### 4.2 开启监督

「监督」页点「开启监督」——需已授权悬浮窗 + 使用情况访问。开启后：
- 前台是勾选的娱乐应用 → 屏幕出现**悬浮计时胶囊**「⏱ 已使用 mm:ss」。
- 切换出去 / 锁屏 → 计时停止并重置；再进入重新计时。

> 胶囊可**按住拖动**到屏幕任意位置，位置会被记住，下次还在原地。下拉通知栏、打开应用小窗**都不会打断计时**（只真正全屏切走才结束）。

### 4.3 提醒阈值

- 「监督」页 →「提醒阈值」，默认 **30 / 60 / 90 分钟**（可改成任意正整数分钟，逗号分隔）。
- 使用时长到阈值 → 弹出**提醒弹窗**「时间到 ⏰」，三个按钮：

| 按钮 | 行为 |
|---|---|
| **再玩5分钟** | 本次阈值顺延 5 分钟，稍后再提醒。**单次会话最多 3 次**，用尽后按钮变灰显示「已用完」 |
| **退出应用** | 进入退出引导页 |
| **关闭提醒** | 本次不再打扰，跳到下一个更高阈值；没有更高的阈值则本次会话不再提醒（悬浮计时继续） |

### 4.4 退出引导页

点「退出应用」→ 全屏「**该走了 🌿**」，10 秒倒计时，期间若已切出则祝贺、仍在使用则温和提示。可提前点「我准备好了」收起。

> 技术说明：Android 第三方 App 无法强制关闭其他应用，此页是「引导你主动离开」的降级方案。

## 五、功能详解：定时提问（F2）

### 5.1 新增问题计划

「提问」页 →「＋ 新增」：

1. **时间**：时 / 分两个下拉（24 小时制，默认 6:00）。
2. **问题内容**：任意文本。
3. **重复规则**（两种模式）：
   - **按星期**：预设「每日 / 工作日 / 周末」，或逐个勾选周一~周日。
   - **每隔 N 天**：选 2~30，从今天起按自然日每隔 N 天触发一次。

### 5.2 到点弹窗提问

到点 → 弹窗提问（若在后台，需悬浮窗权限才能弹出），可**自由文本作答**，自动附带「当前正在使用的 App」场景信息。

- **通知兜底**：即使弹窗被 ROM 节流，也会发一条高优先级通知，点通知即可回答。
- **闹钟重排**：触发后自动登记下一次，实现每天/每周/每隔 N 天的重复。

### 5.3 待回答 / 补答

到点时没空（锁屏、开会…）→ 该问题进入「**待回答**」列表挂起。打开 App 可：
- **补答**：填写答案，记录会标注「补答于 xx:xx」（超过 5 分钟视为补答）。
- **忽略**：删除这条记录。

### 5.4 修改问题同步日记

修改一条计划的问题文本后，**历史回答记录的快照**会同步更新，已汇编日记里也会反映新问题（需触发一次汇编/回答变化）。

## 六、功能详解：日记（F3）

顶部「**日历 | 封面**」切换两种入口，底部是日记内容区。

### 6.1 汇编

- 今天还没有日记 → 点「**汇编今日日记**」自动生成。
- 已有日记 → 点「**重新汇编**」按最新数据刷新。
- 汇编内容：日期 / 天气（可手填）/ 娱乐使用统计 / 定时提问回答 / 当日小结。

### 6.2 阅读与编辑

- 正文是 Markdown 渲染（标题、列表、引用、**粗体**、*斜体*），底下垫**笔记本横线**（手账感）。
- 「编辑」进入整篇编辑；手动编辑过的日记会被标记保护，**自动汇编不会覆盖你的修改**（只会刷新「娱乐使用 / 定时提问 / 小结」三个数据小节）。

### 6.3 封面

- 每篇日记可设封面 = **天气 emoji（大字）+ 心情底色**，点「封面」选择，可「清除封面」。
- **自动建议**：汇编时若未设封面，会按正文「天气」文本和回答里的情绪关键词自动生成（如「晴」→☀️，「好着呢」→😊），可手动改。

### 6.4 翻阅（像翻实体日记本）

- **日历模式**：点某天 → 下方直接显示该天日记；**左右滑动**在相邻有日记的天之间翻页。
- **封面模式**：封面墙网格（每篇封面 = 底色 + 天气 emoji + 日期），**点某篇封面 → 全屏翻阅**，直接打开该书页，可继续左右滑动、编辑。
- 只翻「有日记」的日期，空白日跳过。

### 6.5 自动同步回答

补答 / 新增回答 / 改题后，当天已汇编的日记会**自动刷新**（未手动编辑过的整篇更新；编辑过的只更新数据小节）。

## 七、功能详解：统计

「统计」页顶部切换 **周报（最近 7 天） / 月报（最近 30 天）**，滚动到今日。

| 区块 | 内容 |
|---|---|
| **总览** | 娱乐总时长 / 日均 / 提问条数 / 回答率 |
| **每日娱乐时长** | 柱状图：纵轴有时长刻度；**点某根柱子看当天时长**；今天为深色柱；有峰值标注 |
| **娱乐应用排行** | 前 5 名应用横条 + 时长 |
| **定时提问** | 按时答 / 补答 / 未答 + 回答率进度条 |

## 八、功能详解：导出

「导出」页：

| 按钮 | 导出内容 | 用途 |
|---|---|---|
| **导出 Markdown** | 全部日记合并为一个 `.md` | 阅读 / 转发 / 发布 |
| **导出 JSON** | 娱乐清单 / 问题计划 / 回答记录 / 日记的结构化备份 | 备份 / 迁移 / 程序化分析 |

- 点按钮 → 系统文件选择器（SAF）**由你选保存位置** → 写入后提示成功。
- 文件名带时间戳（如 `TimeNote_日记_20260804_1930.md`）。
- **零权限、零联网**，文件在你自己的手机里。

### 导入恢复（JSON 备份）

「导出」页 →「**导入恢复**」→ 选择之前导出的 JSON 备份：

- 系统先**校验**是否为 TimeNote 备份，并展示内容预览（娱乐/计划/回答/日记各多少条）。
- 选择导入方式：
  - **合并导入**（推荐）：保留现有数据，跳过重复项。
  - **覆盖导入**：清空当前全部数据后再导入（**不可恢复**，操作前注意备份）。
- 导入成功后自动重排定时闹钟，恢复的计划立即生效。

## 九、推荐使用方式

**早晨**：设 1~2 条早晨提问（如「今天打算怎么安排？」）→ 每天到点自省。
**白天**：监督开着，娱乐应用一用就浮现计时，到阈值弹窗提醒你休息。
**晚上**：22:00 问一条「今天有什么后悔的事吗？」→ 睡前打开日记，汇编今天的记录、补答漏掉的提问、顺手设个封面。

一周后看「统计」页的周报，了解自己的时间模式。

## 十、数据与隐私

- **存储**：全部存在本机 Room 数据库（`timenote.db`），无账号、无云端。
- **联网**：**禁止任何网络请求**（隐私红线）。
- **导出即备份**：用「导出 JSON」把数据文件备份到手机本地（或转存电脑）。
- **删除**：卸载 App 会清空本机数据；建议先导出再卸载。

## 十一、常见问题 FAQ

**Q1 悬浮计时器不出现？**
检查：①「监督」页权限卡片里悬浮窗、使用情况访问都已开启；②该应用已在娱乐清单里勾选；③监督服务已开启。

**Q2 到点提问不准时 / 延迟？**
先授权「精确闹钟」；剩余延迟多为手机厂商的省电节流，App 层无法完全消除。另需允许自启动，否则开机后打开一次 App 重新登记闹钟。

**Q3 到点没弹窗？**
弹窗在后台弹出受悬浮窗权限 + ROM 限制；此时会发一条**通知兜底**，点通知即可回答。

**Q4 提醒阈值被我调小了？**
验证时可能改成了 1 分钟，记得在「监督 → 提醒阈值」恢复为 `30,60,90`。

**Q5 打开小窗 / 下拉通知栏会打断计时？**
已修复：只有「基本铺满屏幕的应用窗口」才算切走，小窗、通知栏、锁屏分别处理（锁屏会正确重置）。

**Q6 封面没有心情？**
自动建议是关键词匹配（正面/负面关键词），猜不准时手动点「封面」改选即可。

**Q7 修改问题后日记里没变？**
问题文本变更会同步历史记录，但已汇编日记需重新汇编（或等待下次回答变化）才刷新。

**Q8 怎么备份 / 迁移？**
「导出」页：先「导出 JSON」留底，换手机/清数据后点「导入恢复」选备份文件，用「合并」或「覆盖」恢复。建议日常「合并」，整机迁移用「覆盖」。

## 十二、开发者附录

### 12.1 技术栈与环境

| 项 | 值 |
|---|---|
| 语言 / UI | Kotlin + Jetpack Compose（Material3） |
| 数据库 | Room（SQLite，schema v4） |
| 前台检测 | UsageStatsManager + AccessibilityService（实时兜底） |
| 定时 | AlarmManager（精确闹钟 + 降级窗口） |
| 悬浮窗 | WindowManager（TYPE_APPLICATION_OVERLAY） |
| 版本 | compileSdk 35 / minSdk 26 / targetSdk 35，AGP 8.12，Kotlin 2.1.20，Compose BOM 2025.05.01 |

本机构建环境：
```
JAVA_HOME=<JDK 安装路径>
ANDROID_HOME=<Android SDK 路径>
./gradlew.bat assembleDebug    # 调试包（app-debug.apk，约 10.8 MB）
./gradlew.bat assembleRelease  # 正式包（app-release.apk，约 1.7 MB，R8 混淆 + debug 签名）
```

### 12.2 项目结构

```
app/src/main/java/com/timenote/
├── MainActivity.kt             # 底部 5 Tab 导航
├── data/                       # Room：entity / dao / TimeNoteDatabase（v1→v4 迁移）
├── monitor/                    # F1：无障碍服务、UsageStats、SessionTracker、FloatTimerService
├── question/                   # F2：AlarmReceiver、Scheduler、PromptActivity、BootReceiver
├── diary/                      # F3 汇编：DiaryAssembler（含小结增强、封面建议）、DiaryAutoSync
├── ui/
│   ├── entertainment/          # 监督页
│   ├── question/               # 提问页
│   ├── diary/                  # 日记页（日历/封面/翻页/编辑）＋ Covers 封面工具

│   ├── export/                 # 导出页

```
