## 可选补充（非必填）

想细化到每个功能的动图/截图，可按下面命名放入，README 无需改动：

| 文件名 | 演示内容 |
|---|---|
| `demo-monitor.gif` | 娱乐监督：进入娱乐 App 浮出计时胶囊 → 拖动 → 阈值弹窗（再玩5分钟 / 退出应用） |
| `demo-question.gif` | 定时提问：到点弹窗提问 → 作答（含场景信息）→ 错过补答 |
| `demo-diary.gif` | 日记本：汇编今日日记 → 设置封面 → 封面墙 → 左右翻页 |
| `screenshot-stats.png` | 统计页：周报 / 月报图表 |
| `screenshot-export.png` | 导出页：导出 Markdown / JSON |

录制建议：

- 用手机系统自带的屏幕录制，或 `adb shell screenrecord --time-limit 15 /sdcard/demo.mp4`。
- 场景尽量包含真实操作（进入娱乐 App → 计时器出现 → 达到阈值弹窗），比静止截图更有说服力。
- MP4 可以直接放（GitHub 页面内嵌播放）；GIF 仅建议用于 10~15 秒的高光片段，太长会膨胀到几十 MB。
