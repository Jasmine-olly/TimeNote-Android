## 📌 项目背景

**手机上时间总是「不知不觉」地溜走——刷完一天，却想不起自己到底看了什么、今天感受如何。**

TimeNote 要解决的正是这个痛点：它不封锁、不强拆，只是把「时间流逝」温柔地亮给你看，定时问你几个问题，再把一天的使用数据与感受碎片自动沉淀成一篇日记，让你重新拥有「看见时间」和「回看自己」的能力。

## ✨ 核心功能

### 🎬 完整功能演示

一段录屏带你走完三大核心功能：**娱乐监督 → 定时提问 → 日记沉淀**。

<video src="assets/demo.mp4" controls muted playsinline style="max-width: 100%; border-radius: 12px;"></video>

### ⏱ 娱乐监督 —— 把看不见的时间「浮现」出来

勾选手机里的娱乐应用（小红书、淘宝、抖音…），一使用就在屏幕上浮出**计时胶囊**「⏱ 已使用 12:34」，可拖动、记忆位置。达到阈值（默认 30/60/90 分钟）弹出提醒，给你三个选择：

| 按钮 | 行为 |
|---|---|
| **再玩5分钟** | 本次阈值顺延 5 分钟（单次会话最多 3 次） |
| **退出应用** | 进入「该走了 🌿」引导页，10 秒倒计时温柔监督 |
| **关闭提醒** | 本次不再打扰，计时继续 |

> 悬浮计时 · 阈值弹窗 · 退出引导

### ❓ 定时提问 —— 在设定时刻，采集当下的自己

自定义「时间 → 问题」配对：`22:00 → 今天有什么后悔的事吗？` 到点弹出提问卡片，自由作答并自动附带场景信息（作答时间、当前正在使用的 App）。忙没空？进入「待回答」列表，随时补答。

- 重复规则支持 **每日 / 工作日 / 周末** 或 **每隔 N 天**
- 后台到点弹窗被系统节流时，**通知兜底**：点通知即可回答

> 到点弹窗提问 · 待回答补答

### 📓 日记本 —— 每天自动沉淀，像翻实体日记本一样回看

每天自动把 **娱乐统计 + 提问回答 + 当日小结** 汇编成一篇 Markdown 日记（含娱乐高峰时段、最常用应用占比），可手动编辑——你编辑过的地方，自动汇编永远不会覆盖。每篇可设 **天气 emoji + 心情底色** 封面，日历圆点索引、封面墙总览，支持**左右翻页**。

> 自动汇编 · 手动编辑 · 封面索引 · 左右翻页

### 📊 统计 · 📤 导出

- **统计**：周报 / 月报可视化 —— 每日娱乐时长柱状图、应用排行、提问回答率
- **导出**：全部日记一键导出 **Markdown**，全量数据导出 **JSON**（可再次导入恢复，支持合并/覆盖）

## 🙋 我的角色

这个项目我承担的是 **产品经理 + 设计师 + 开发组织者** 的角色，而不仅仅是写代码：

### 1. 需求分析
- 从「刷手机时间无感」的痛点出发，与用户多轮沟通，写出完整 **PRD**（产品需求文档）：功能拆解（F1 娱乐监督 / F2 定时提问 / F3 日记本）、数据与隐私红线（**纯本地、零联网、仅手动导出**）、技术选型论证、MVP → V1.1 → V1.2 版本规划。
- 关键产品决策：识别到「Android 第三方应用无法强制关闭其他应用」的系统限制，设计了**「退出引导页 + 倒计时」**的降级方案；识别到国产 ROM 对悬浮窗/自启动的限制，设计了权限引导与兜底策略。

### 2. 产品设计
- **信息架构**：底部 5 Tab（监督 / 提问 / 日记 / 统计 / 导出），每个功能的入口与层级都经过梳理。
- **交互流程**：悬浮计时胶囊 → 阈值弹窗三按钮 → 退出引导倒计时；定时提问 → 错过补答 → 自动同步进日记，形成完整闭环。
- **视觉体系**：定义「治愈手绘风」——鼠尾草绿 `#8FA98B` + 奶油纸 `#F6F1E5` + 暖墨棕 `#4A4438`，手绘虚线描边、笔记本横线、手绘波浪线、日记封面（天气 emoji + 心情底色），让工具「温柔」而非「监控」的气质贯穿始终。

### 3. AI 辅助开发
- 以 **Claude Code** 为「AI 结对工程师」贯穿全流程：把 PRD 翻译为可编译的工程实现（Kotlin/Compose 项目骨架 → Room 数据层 → 三大功能 → 统计/导出/导入）。
- 走「**构建 → 装机 → 真机验证 → 修复**」的迭代闭环：累计修复 10+ 个真机问题（如 ROM 节流导致闹钟延迟、无障碍服务误判前台应用、手动编辑被自动汇编冲掉、前台服务被系统回收等）。
- 全程维护产品文档（使用说明书 / 技术栈说明 / 修复日志），让项目可以被任何人接手、继续演进。

> **一句话总结：我负责「决定做什么、长什么样、好不好用」，AI 负责「怎么写、怎么快速验证」——这是一个人用 AI 完成从 0 到 1 完整产品闭环的实践。**

## 🛠 技术栈

| 层 | 选型 |
|---|---|
| 语言 / UI | **Kotlin** + **Jetpack Compose**（Material3） |
| 本地存储 | **Room**（SQLite） |
| 定时任务 | **AlarmManager**（精确闹钟 + 降级窗口） |
| 前台应用检测 | **UsageStatsManager** + **AccessibilityService**（实时兜底） |
| 悬浮窗 | **WindowManager**（TYPE_APPLICATION_OVERLAY） |
| 最低版本 | Android 8.0（minSdk 26）/ targetSdk 35 |

> 选型原因：悬浮窗、前台检测、全屏弹窗都是 Android 深度系统能力，因此选择**原生 Kotlin** 而非跨平台框架。

**AI 开发工具**：**Claude Code** —— 需求分析、架构设计、编码实现、真机验证、文档维护，全流程 AI 辅助。

## 🔒 隐私设计

- **零联网**：代码层面禁止任何网络请求，无账号、无云端、无统计上报。
- **纯本地存储**：所有数据存在本机 Room 数据库。
- **导出即备份**：数据导出为 Markdown / JSON 保存在你自己的手机里，可随时导入恢复。
